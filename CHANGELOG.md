# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2026-09-30

### Added

- reveal-on-scroll component
- staggered grid component
- magnetic button interaction
- accessible word-by-word text reveal
- scroll progress indicator
- pinned-section component
- horizontal-scroll showcase component
- reduced-motion support
- setup and cleanup patterns
- WordPress conditional enqueue example
- esbuild production bundling
- JavaScript syntax checks
- PHP syntax validation
- GitHub Actions quality workflow
- accessibility, performance, and WordPress integration documentation

### Changed

- package version promoted from `0.1.0` to `1.0.0` for the first stable tagged release
