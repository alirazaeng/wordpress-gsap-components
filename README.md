# WordPress GSAP Components

Reusable, performance-conscious GSAP animation and interaction components for modern WordPress frontends.

This repository demonstrates how to add polished motion to WordPress without turning animation into a performance, accessibility, or maintenance problem.

## Goals

- reusable GSAP components instead of page-specific animation spaghetti
- progressive enhancement: content remains usable without JavaScript
- reduced-motion support
- clean setup and teardown
- responsive behavior
- WordPress-friendly loading
- ScrollTrigger used only where it adds real value
- examples that can be adapted to themes, blocks, or custom plugins

## Planned components

- reveal on scroll
- staggered grids
- text reveal
- magnetic buttons
- scroll progress
- pinned sections
- horizontal scroll sections

## Integration

The project will provide both ES-module source files and a WordPress-oriented bundle workflow.
